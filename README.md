# 🚗 Streamlit Car Racing Game

A simple 1–2 player car racing game built using Streamlit and 
streamlit-drawable-canvas. You can play against another human or 
against an AI opponent.

This app is designed to run on Streamlit Community Cloud.

---

## 🎮 Features
- 1 Player vs AI mode
- 2 Player local multiplayer mode
- WASD + Arrow key controls
- Simple AI movement
- Canvas-based rendering
- Win detection

---

## 🕹 Controls

### Player 1 (Red Car)
- W = Up
- S = Down
- A = Left
- D = Right

### Player 2 (Blue Car)
- Arrow Keys

### AI Opponent
- Moves automatically

---

## 🚀 Deploy on Streamlit Cloud

1. Upload all files to a GitHub repository  
2. Go to https://share.streamlit.io  
3. Click "New App"  
4. Select your repository  
5. Set the app file to `app.py`  
6. Deploy and play!
